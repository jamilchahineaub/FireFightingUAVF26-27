# Step 4: aerodynamic parameters for the Gazebo LiftDrag plugin

Generated by `aero/aero_params.py`. Every number below is computed in that script from the CAD areas (`cad/geometry.json`) and the SolidWorks mass properties (`mass/mass_props.json`). Angles in the plugin are in radians; degrees are given alongside.

## Flight condition

- weight W = 10.50 kg x 9.81 = 103.0 N (tank full)
- wing: S = 0.6980 m^2 (CAD planform, both halves), b = 2.51 m, c = 0.278 m, AR = b^2/S = 9.025
- design cruise V = 20.0 m/s: q = 245.0 Pa, Re = Vc/nu = 3.81e+05, M = 0.059 (beta = 0.9983, so compressibility is ignored)
- cruise lift coefficient CL = W/(qS) = 0.602

## Wing (NACA 4417), one LiftDrag element per half

Zero-lift angle and pitching moment from thin airfoil theory on the 4417 camber line (m = 0.04, p = 0.4), integrated numerically with x = (1 - cos theta)/2:

- alpha_L0 = -(1/pi) int (dz/dx)(cos theta - 1) dtheta = **-4.15 deg** (-0.0725 rad). Abbott & von Doenhoff list about -4.0 deg for the 4415 and 4418, so this is consistent.
- A1 = 0.1630, A2 = 0.0277, cm_c/4 = (pi/4)(A2 - A1) = -0.106

2-D lift slope: a0 = kappa 2 pi = 0.95 x 2 pi = 5.969 /rad (0.1042 /deg).

Finite-wing slope, DATCOM/Helmbold form (Raymer eq. 12.6), unswept:

    a = 2 pi AR / (2 + sqrt(4 + (AR beta/kappa)^2)) = 2 pi 9.025 / (2 + sqrt(4 + (9.025 x 0.9983 / 0.95)^2)) = **4.850 /rad**

Stall: CLmax_2D = 1.35 (4417 at Re ~4e5, A&vD values scaled down for the low Re), CLmax_3D = 0.9 x CLmax_2D = 1.215. Angle from the zero-lift line: CLmax/a + 1.5 deg = 14.35 + 1.5 = **15.85 deg** (0.2767 rad), i.e. 11.7 deg to the chord, 9.0 deg body AoA.

Plugin offset: forward = body +X, upward = body +Z, so a0 = i_w - alpha_L0 = 2.65 + 4.15 = **6.80 deg** (0.1188 rad). Zero lift then happens at a body AoA of -6.80 deg.

Drag. The plugin only knows cd = |cda alpha| with alpha measured from zero lift, so it has no separate CD0. The whole-aircraft drag at the cruise point is put on the two wing halves:

| component | Cf (turbulent) | form factor | Q | S_wet [m^2] | CD0 contribution |
|---|---:|---:|---:|---:|---:|
| hull (step + spray rails, Q = 1.25) | 0.00384 | 1.172 | 1.25 | 1.258 | 0.01014 |
| nacelles (Q = 1.3) | 0.00494 | 1.069 | 1.30 | 0.225 | 0.00221 |
| floats + pylons (Q = 1.2) | 0.00546 | 1.200 | 1.20 | 0.111 | 0.00125 |
| h-stab + elevator | 0.00556 | 1.386 | 1.05 | 0.456 | 0.00528 |
| fin + rudder + finlets | 0.00527 | 1.261 | 1.05 | 0.356 | 0.00356 |
| wing profile drag (4417 at Re 4e5) | | | | | 0.01200 |
| leakage and protuberances | | | | | +10 % of the non-wing items |
| **CD0** | | | | | **0.0367** |

- Oswald factor (Raymer eq. 12.48) e = 1.78(1 - 0.045 AR^0.68) - 0.64 = 0.782
- at cruise: CDi = CL^2/(pi e AR) = 0.0164, CD = 0.0530, L/D = 11.4, drag = 9.1 N
- plugin alpha at cruise = CL/a = 0.1242 rad, so **cda = CD/alpha = 0.427 /rad**. That reproduces the polar at cruise, overestimates drag a little near stall and underestimates it near zero lift.

Post-stall (rough): lift falls to 60 % of CLmax 15 deg past stall, cla_stall = -0.4 CLmax / 15 deg = -1.856 /rad; drag reaches a flat-plate-like CD ~ 1 at 45 deg, cda_stall = 1.733 /rad.

Centre of pressure: quarter chord of each half at its area centroid, cp = (-0.0694, +/-0.6275, -0.0032) m in base_link. A single point per half at b/4 gives roll damping Clp = -2 a (y/b)^2 = -0.606, close to DATCOM for a rectangular AR 9 wing (about -0.6), so the area centroid is a reasonable single point.

Pitching moment: the 4417 has cm_ac = -0.106, a constant. LiftDrag can only do cm = cma alpha, which would add a fake pitch stiffness, so cma = 0 on the wing and the camber moment is left out. In practice the sim needs a bit less up-elevator to trim than the real aircraft would.

## Ailerons (coupled to the wing halves)

- chord ratio E = cf/c = 0.250; thin airfoil: theta_h = acos(2E - 1) = 2.0944, tau = 1 - theta_h/pi + sin(theta_h)/pi = **0.609**, dcm/ddelta = -1/2 sin(theta_h)(1 - cos(theta_h)) = -0.650
- flapped share of a half wing: c (y1 - y0) / S_half = 0.278 x 0.402 / 0.3490 = 0.320
- half-wing lift per radian: dCL/ddelta = a tau (S_flapped/S_half) = 4.850 x 0.609 x 0.320 = 0.946
- the plugin puts that lift at the half-wing cp (y = 0.6275) but it really acts at the aileron centre (y = 0.994), so the coefficient is scaled by 1.584 to keep the roll moment right: **control_joint_rad_to_cl = 1.498**. Ailerons move in opposite directions, so the extra lift cancels and only the roll moment remains.
- resulting roll control power Cl_delta_a = 2 dCL S_half y_ail / (S b) = 0.3745 /rad per aileron degree of differential (both deflected by delta)
- cm_delta = 0.9 dcm/ddelta (S_flapped/S_half) c = -0.05204 (chord factor because the plugin applies cm q S)

## Horizontal tail (NACA 0016) with elevator

- S_h = 0.2237 m^2 (CAD, gross through the fin), span 0.936 m, AR_h = 3.916, incidence 0 (OBJ)
- a_h = 2 pi AR_h / (2 + sqrt(4 + (AR_h/kappa)^2)) = **3.742 /rad**
- downwash: deps/dalpha = 2 a_w / (pi AR) = 0.3421; at zero body AoA the wing CL is a_w a0_w = 0.576, so eps0 = 0.0406 rad (2.33 deg)
- the plugin sees free-stream flow at the tail, so downwash and the tail dynamic pressure ratio (eta_t = 0.9) are folded into the coefficients:
    cla_eff = a_h eta_t (1 - deps/dalpha) = 3.742 x 0.9 x 0.6579 = **2.216 /rad**
    a0_eff = (i_t - deps/dalpha a0_w) / (1 - deps/dalpha) = **-0.0618 rad** (-3.54 deg)
- stall: CLmax_t = 0.9 x 1.2 = 1.08, true tail angle 18.0 deg, in plugin alpha (divide by 1 - deps/dalpha) **0.4785 rad**
- elevator: E = 0.397, tau = 0.746; the CAD elevator covers 0.854 of the full-span flapped strip (fin gap, rudder cut-outs); **control_joint_rad_to_cl = a_h tau coverage eta_t = 2.145**, cm_delta = -0.09750
- drag: cda linearised at 5 deg with CD0 = 0.008 and e = 0.8, cda = 0.216 /rad
- tail volume V_H = S_h l_h / (S c) = 0.2237 x 0.8033 / (0.6980 x 0.278) = 0.926 (the CL-415 has a big tail)

## Vertical tail (NACA 0012) + finlets, one element, with rudder

- fin + rudder above the deck: S_v = 0.1264 m^2, height 0.4343 m, geometric AR = 1.492; the hull below and the stab at mid-height act as end plates, effective AR = 1.5 x 1.492 = 2.239
- half-chord sweep 21.8 deg; a_v = helmbold(AR_eff, sweep) = 2.690 /rad
- finlets (two, on the stab): 0.0480 m^2 total, AR 2.13 each, a_fl = 2.673 /rad
- one element for all vertical area: S = 0.1744 m^2, cla = (a_v S_v + a_fl S_fl)/S x eta_v = **2.417 /rad**, a0 = 0 (symmetric), cp = area-weighted quarter-chord point (-0.8798, 0, 0.1560)
- forward = +X, upward = +Y, so the plugin angle is the sideslip; alpha_stall = 23 deg (low AR fins stall late)
- rudder: E = 0.380 (mean of root and tip), tau = 0.732. Positive rudder = trailing edge left, which pushes the tail right (-Y), so **control_joint_rad_to_cl = -a_v tau eta_v S_v/S = -1.284**, cm_delta = 0.10940
- drag: cda = 0.209 /rad (linearised at 0.1 rad sideslip)
- vertical tail volume V_V = S l_v / (S_w b) = 0.080

## Static margin check

- neutral point from the surfaces only (what the plugin model contains): h_n = 0.25 + eta V_H (a_h/a_w)(1 - deps/dalpha) = 0.673
- hull destabilising term (Gilruth/Raymer, K_f = 0.011/deg at 39 % hull length): dCm/dalpha = 0.292 /rad, shifts h_n forward by 0.060, so h_n ~ 0.613 for the real aircraft
- full: CG at 27.1 % MAC, static margin 34 % MAC (plugin model 40 %)
- empty: CG at 28.0 % MAC, static margin 33 % MAC (plugin model 39 %)
- a big margin, as expected with V_H near 0.9. Elevator authority is the thing to watch at low speed.

## Propulsion (MulticopterMotorModel, one per propeller)

- prop D = 0.3554 m (OBJ scaled), 14x7 class. Static coefficients assumed CT = 0.085, CP = 0.045.
- max 8500 rpm = 890.1 rad/s: T_max = CT rho n^2 D^4 = 33.3 N per motor, 0.65 T/W with both (tank full); shaft power 889 W each
- motorConstant = T_max / w_max^2 = **4.2079e-05 N/(rad/s)^2**, momentConstant = (CP/2pi) D / CT = **0.0299 m**
- cruise needs 9.1 N total. The plugin thrust is static (no advance-ratio drop), so in flight it gives more thrust per rpm than a real prop would.
- props counter-rotate: left one clockwise seen from behind (positive about +X), right one counter-clockwise, both blades going up on the outboard side. The CAD blades are pitched to match.

Known limits of this model: no constant wing pitching moment, no downwash lag, no propeller slipstream, no hull lift or side force, linear control effectiveness up to the joint limits, and drag tuned to one point. Good enough for controller work and sanity flights; swap to AdvancedLiftDrag with a full derivative set once wind-tunnel or XFLR5 data exists.

Stall speed at 10.5 kg: V_s = sqrt(2W/(rho S CLmax)) = 14.1 m/s.
